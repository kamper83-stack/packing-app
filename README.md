# Packing App 🧳

A React-based packing list manager to help you prepare for trips.

## Features

- **Add items** with bag type — Suitcase 🧳 or Backpack 🎒
- **Check/uncheck** items as you pack them
- **Filter** items by: All / Packed / Unpacked
- **Progress bar** showing packing completion percentage
- **Delete with confirmation** modal
- **Persistent storage** — list saved to localStorage

## Tech Stack

- React (Create React App)
- Styled Components
- LocalStorage

## Getting Started

```bash
npm install
npm start
```

Open [http://localhost:3000](http://localhost:3000) to view in browser.
